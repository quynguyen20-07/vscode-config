# VS Code Config Setup Extension

This extension installs JetBrains Mono font variants and copies a custom VS Code CSS file into the user `.vscode` directory.

## Commands

- `VS Code Config: List JetBrains Fonts`
- `VS Code Config: Install Selected JetBrains Mono Fonts`
- `VS Code Config: Setup VS Code Appearance`

## Notes

- Uses the bundled fonts in `fonts/ttf`.
- On Linux it refreshes the font cache automatically.
- On macOS it installs fonts to `~/Library/Fonts`.
- On Windows, font install may not be automatic and may require manual copy.
