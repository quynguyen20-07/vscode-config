# vscode-config

> Bộ cấu hình Visual Studio Code chuyên nghiệp dành cho Next.js và NestJS.

---

## ✨ Giới thiệu

`vscode-config` là kho chứa hai profile VS Code được tinh chỉnh kỹ càng cho:

- `⚛️ NextJS.Pro.code-profile`: trải nghiệm Next.js tối ưu với giao diện Catppuccin Mocha, hỗ trợ Tailwind CSS, Emmet, linting và format tự động.
- `🦅 NestJS.Pro.code-profile`: cấu hình NestJS chuyên sâu, tối ưu backend, hỗ trợ Prisma, Docker, REST Client và môi trường làm việc cao cấp.

Mỗi profile được thiết kế để mang lại:

- Giao diện đẹp mắt, chuyên nghiệp
- Trải nghiệm coder mượt mà và tập trung
- Hiệu suất làm việc tốt hơn với cài đặt giảm lag
- Tự động hóa format, lint và quản lý import

## 🌟 Điểm nổi bật

- Theme: `Catppuccin` (Mocha / Macchiato)
- Icon theme: `material-icon-theme`
- Font mặc định: `JetBrains Mono`
- Tự động format khi lưu với `Prettier`
- Lint & fix on save cho ESLint
- Hỗ trợ `Tailwind CSS` và `Emmet` cho frontend
- Hỗ trợ `Prisma`, `Docker`, `REST Client` cho backend
- Tối ưu workspace với cấu hình `files.watcherExclude`
- Trang bị `GitLens` và `Error Lens` để debug trực quan

## 🧩 Nội dung trong repo

- `⚛️ NextJS.Pro.code-profile`
  - Cấu hình dành cho dự án Next.js
  - Tập trung vào phát triển giao diện, frontend và trải nghiệm web hiện đại

- `🦅 NestJS.Pro.code-profile`
  - Cấu hình dành cho dự án NestJS
  - Tối ưu cho backend, REST API, Docker và lập trình server-side

## 🚀 Hướng dẫn sử dụng

1. Sao chép profile vào thư mục VS Code `code-profiles`.
2. Mở VS Code, vào `Profiles` và chọn profile mong muốn.
3. Cài các extension được đề xuất hoặc có trong profile.
4. Khởi động lại VS Code để áp dụng đầy đủ cấu hình.

> Đây là bộ cấu hình dành cho lập trình viên chuyên nghiệp, ưu tiên hiệu quả và trải nghiệm cao cấp.

## 💎 Đẳng cấp thế giới

`vscode-config` không chỉ là một bộ profile đơn thuần — nó là bản thiết kế phong cách làm việc hiện đại cho coder muốn nâng tầm môi trường phát triển.

## 📌 Lưu ý

- Bạn có thể điều chỉnh thêm theo nhu cầu cá nhân.
- Sử dụng cùng các extension phù hợp để đạt trải nghiệm tốt nhất.
